## Зачем мы создали этот проект?

Давайте начистоту: мы обожаем Claude Code! Но столкнулись с бесящей проблемой. Если вы не в США, веб-поиск просто не работает. А когда вы исследуете что-то или нужно найти информацию во время программирования, это реально раздражает.

Поэтому мы отправились на поиски решений. И знаете что? Мы сделали потрясающее открытие! Есть API, которые предоставляют не только бесплатные возможности поиска, но и доступ к впечатляющим языковым моделям. Некоторые из этих моделей на самом деле *лучше* понимают код и обрабатывают длинные контексты, чем можно было бы ожидать!

Это заставило нас подумать: "А что если мы сможем дать пользователям Claude Code лучшее из обоих миров?"

## Что делает Claude Code Sugar

Вместо того чтобы взламывать сам Claude Code (что было бы кошмаром для поддержки), мы построили легкий прокси, который находится между Claude Code и этими API. Думайте о нем как о переводчике, который говорит на языке Claude Code и на языке этих мощных API.

Результат? Вы получаете:
- ✅ Все потрясающие функции Claude Code
- ✅ Веб-поиск, который реально работает по всему миру
- ✅ Доступ к экономичным, высокопроизводительным моделям
- ✅ Совместимость с протоколом OpenAI (стандарты важны!)
- ✅ Никаких изменений в Claude Code (обновления просто работают)

**Примечание: Этот проект предназначен для академических и исследовательских целей.**

## Готово за 30 секунд ⚡

Готовы прокачать свой опыт с Claude Code? Просто запустите это:

```shell
bash -c "$(curl -fsSL https://raw.githubusercontent.com/claude-code-sugar/claude-code-sugar/refs/heads/main/install.sh)"
```

Установщик попросит API-ключ для поиска - просто зайдите на [открытую платформу iFlow](https://iflow.cn/?open=setting), получите бесплатный ключ и вставьте его. Проще простого! 🔑

Затем запускайте Claude Code как обычно:

```shell
claude
```

Вот и всё! Теперь вы используете Claude Code с глобальными возможностями поиска и доступом к экономичным моделям. 🚀

## Хотите попробовать другие модели? 🎛️

По умолчанию Claude Code Sugar использует модель Qwen3-Coder, которая довольно надёжна для большинства задач программирования. Но может быть, вы хотите поэкспериментировать с разными моделями или использовать свои собственные API-эндпоинты!

Без проблем! Просто отредактируйте `~/.config/claude-code-sugar/config.json` и настройте как хотите:

```json
{
  "baseURL": "ваш базовый URL OpenAI",
  "apiKey": "ваш API-ключ", 
  "modelMapping": {
    "claude-3-5-haiku-20241022": "ваша модель для простых задач",
    "claude-3-7-sonnet-20250219": "ваша модель для средних задач", 
    "claude-sonnet-4-20250514": "ваша модель для сложных задач",
    "claude-opus-4-20250514": "ваша модель для тяжёлых задач"
  },
  "searchApiKey": "ваш ключ API поиска"
}
```

Маппинг моделей позволяет назначать разные модели для разных уровней сложности - довольно умно для оптимизации как производительности, так и затрат! 💰
