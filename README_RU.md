# Claude Code Sugar

**Через Claude Code Sugar вы можете разблокировать некоторые ограниченные функции Claude Code и поддержать адаптацию к другим моделям.**

Первоначальная мотивация этого проекта проистекает из практической проблемы, с которой мы столкнулись при использовании Claude Code: в регионах за пределами Соединенных Штатов нативная функция **веб-поиска** не может использоваться должным образом, что приносит неудобства академической исследовательской работе, требующей поддержки веб-поиска.

В процессе поиска решений мы случайно обнаружили, что отечественный продукт предоставляет открытые API-интерфейсы. Функция поиска не только может использоваться бесплатно, но также интегрирует несколько больших языковых моделей—некоторые из которых превосходно справляются с пониманием кода и обработкой длинного контекста. Это, несомненно, хорошая новость для пользователей Claude Code, которые хотят лучшую экономическую эффективность.

Основываясь на этом открытии, мы разработали проект Claude Code Sugar. Чтобы сохранить всю функциональность Claude Code и поддерживать непрерывные обновления, мы не изменили никакого кода Claude Code, а вместо этого используем легкий прокси-слой для адаптации к этим API-интерфейсам, тем самым решая проблему ограничения функции поиска.

Кроме того, этот прокси также совместим с методами вызова моделей протокола OpenAI.

Через Claude Code Sugar вы можете продолжать наслаждаться мощными возможностями Claude Code, получая при этом более гибкие варианты вызова API.

**Этот проект предназначен только для академических и исследовательских целей**

## Быстрая установка
Используйте следующий скрипт для быстрой установки:
```shell
bash -c "$(curl -fsSL https://raw.githubusercontent.com/claude-code-sugar/claude-code-sugar/refs/heads/main/install.sh)"
```

Процесс установки потребует от вас ввести API-ключ поиска. Перейдите на [открытую платформу iFlow](https://iflow.cn/?open=setting), чтобы подать заявку на получение ключа и ввести его.

Начните использовать Claude Code с низкими затратами:

```shell
claude
```

## Как изменить модель
При прямом использовании установочного скрипта по умолчанию будет использоваться модель Qwen3-Coder, и вы можете использовать её напрямую без изменения каких-либо параметров.
Если вы хотите сменить модель, вы можете отредактировать `~/.config/claude-code-sugar/config.json`, чтобы указать информацию о модели, соответствующей протоколу OpenAI.

Справочный пример config.json:
``` json
{
  "baseURL": "your openai base url",
  "apiKey": "you openai api key",
  "modelMapping": {
    "claude-3-5-haiku-20241022": "your model for small task",
    "claude-3-7-sonnet-20250219": "your model for medium task",
    "claude-sonnet-4-20250514": "your model for large task",
    "claude-opus-4-20250514": "your model for large task"
  },
  "searchApiKey": "your search api key"
}
```
